食物鏈裡的平衡

草、兔子和狼生活在一起。草被兔子吃，兔子被狼吃。一種生物變多或變少，另外兩種也會跟着改變。

第 0 日
草12叢
兔仔7隻
狼3隻
草 兔仔 狼 上面是多，下面是少

現在是平衡狀態。試試把草的數量拉低，或者拉高。

草減少的時候

  1. 草變少，兔子找不到足夠食物。
  2. 兔子的數目下降。
  3. 兔子少了，狼難找獵物，狼也減少。

草增加的時候

  1. 草變多，兔子食物充足。
  2. 兔子的數目上升。
  3. 兔子多了，狼更容易獵食，狼也增加。

兔仔多了之後

  1. 兔仔把草吃少。
  2. 獵物多了，狼也增加。
  3. 草少了，兔仔的食物不夠，兔仔又減少。
  4. 兔仔少了，狼也減少。草再長回來。

動態平衡

  1. 數目會上升，也會下降。
  2. 不會只向一邊一直變。
  3. 吃與被吃互相牽制。
  4. 再按「過一日」，又回到平衡。

數量不會永遠上升或下降。兔子多了會把草吃回去，狼多了又會把兔子吃少。吃與被吃互相牽制，食物鏈便保持平衡。拉動兔子或狼的拉桿，也可以看見這條鏈倒過來影響。
